MODIS Quality Control (QC) Robustness

This analysis tests how applying MODIS MOD11C3 quality-control filters affects nighttime land surface temperature (LST) and the original site scores for Kunlun (Site A) and Vinchina (Site B), using June 2024 data.

Purpose

Assess the robustness of the results to different QC filtering choices without changing the original scoring method.

1. What the MODIS QC Bits Mean

MOD11C3 includes a quality-control flag for each pixel. The relevant bits describe the quality of the LST retrieval.

QC bits Meaning
0–1 Mandatory QA: 0 = good LST, 1 = other quality, 2 = not produced due to cloud, 3 = not produced for another reason.
2 L1B input data quality: 0 = good, 1 = other.
3 Terra/Aqua combined-use flag. Provenance information, not a quality grade.
4–5 Emissivity consistency category. Category 3 is the least consistent.
6–7 Estimated LST error: 0 = ≤1 K, 1 = ≤2 K, 2 = ≤3 K, 3 = >3 K.

These are algorithm-estimated categories, not direct measurements of actual temperature accuracy. QC flags must also be interpreted alongside LST validity.

2. QC Filtering Tiers

Six configurations were evaluated, from the unfiltered baseline to stricter quality requirements.

Tier Filter description
T0 Valid LST pixels only (baseline).
T1 T0 plus mandatory QA categories 0 or 1.
T2 T1 plus estimated LST error category ≤1 (≤2 K).
T4 T1 plus estimated LST error category 0 (≤1 K).
T5 T1 plus good L1B input data quality (bit 2 = 0).
X1 Exploratory: T2 plus emissivity consistency category not equal to 3.

T4 and T5 are alternative stricter filters, not sequential stages. X1 is exploratory. T3 was retired because its original interpretation of the emissivity bits was incorrect.

Key Findings

  • T1, T2 and X1 do not change either site's median. All 16 pixels are retained.
  • T4 changes the Kunlun median from 258.80 K to 262.68 K and increases its score, but only 2 of 16 pixels remain.
  • T5 leaves Vinchina with zero retained pixels, making a two-site comparison impossible.

Limitations

  • The Kunlun T4 result has low pixel support (2 of 16). The Vinchina T5 result is unavailable (0 of 16).
  • The analysis uses June 2024 only, not a full climatology.
  • QC categories are algorithm estimates, not proof of actual temperature accuracy.
  • The analysis does not establish which filter is most accurate or which site is more suitable for a Mars mission.
