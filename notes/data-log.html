Selected multi-year pipeline: 2019–2023

src/download_monthly_range.py uses NASA's earthaccess client and locally configured Earthdata Login credentials. It resolves each product across the requested range through CMR before downloading anything, requires exactly one correctly dated granule for every month, and verifies the HDF signature and file size against CMR metadata. Credentials are not stored in the repository. src/build_features.py --year YYYY --month MM builds a compressed, versioned monthly feature table after resolving exactly one matching granule for each product. Its sidecar manifest records SHA-256 hashes for the table and all three source granules, and explicitly records that MOD13C2 VI and MOD11C3 QC flags are not applied. src/build_monthly_range.py preflights the full requested date range before processing any month, then builds sequentially. The June 2024 table was rebuilt through this path and exactly matches all 577134 rows and columns in the published data/processed/features.csv; it is not a new measurement.

The selected period contains 60 calendar months and 180 raw granules. CMR metadata preflight found exactly one granule per product-month for 2019–2023; the listed sizes total about 10.91 GiB. This is a metadata estimate, not a completed transfer.

src/build_climatology.py --start-year 2019 --end-year 2023 requires all 60 monthly tables and matching source manifests. It computes day-weighted annual means, sample standard deviation across valid annual means, average yearly monthly minima/maxima, and month/year coverage. A cell needs at least 10 valid months in a year and, by the existing 80% default, at least 4 valid years out of 5. A month contributes only when at least 8 of 16 MODIS pixels or 2 of 4 IMERG pixels are valid for that cell; the output records mean valid-pixel support. The climatology manifest carries forward monthly-table hashes, source-manifest hashes, and raw-granule hashes. A changed input hash, unsupported manifest, or grid/row-order mismatch stops the run. Mean feature column names are period-neutral so a shorter window cannot be mislabeled as a ten-year result.

The authenticated granules, 60 monthly tables, and separate 2019–2023 score have not yet been produced; local Earthdata credentials are not configured in this session. Only June 2024 granules exist locally. Published scores, targets, weights, and rankings remain unchanged. The multi-year method uses the same three Earth proxy families; it adds seasonal/interannual context but does not add a measured ice, dust, or global slope factor. MOD11 quality flags remain unfiltered in this pipeline and must be addressed before treating its thermal values as high-quality evidence.

.gitignore ignores *.hdf, *.h5, *.hdf5, and *.he5, so these files stay on this machine and are not committed. The filename in this log is the record.
